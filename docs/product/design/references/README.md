# Reference Atlas

> Referencias comentadas que ensinam *por que* algo funciona,
> nao apenas *como* se parece.

## Template

```markdown
# Reference: <nome>
> Source: <produto> | Captured: <arquivo.png>

## What to leverage (3-4 elementos especificos e por que funcionam)
## What to avoid (3-4 modos de falha)
## Translation to Kerosene (mapeamento concreto: token, componente, movimento)
## Rubric score (avaliacao contra as 6 dimensoes da rubric)
```
